# cssmotion

**Visual CSS animation playground with adjustable timing, transforms and keyframe export.**

![MIT](https://img.shields.io/badge/license-MIT-8b5cf6) ![Local-first](https://img.shields.io/badge/privacy-local--first-06b6d4)

## Quick start

Open `index.html` in a modern browser. No installation, build step, CDN or account is required.

## Features

Visual CSS animation playground with adjustable timing, transforms and keyframe export.

- Responsive single-file interface
- Native browser APIs; no external dependencies
- Local-first and no analytics or telemetry
